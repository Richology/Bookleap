# 书跃本地同步助手 · 未签名测试版

本轮先打通 Chrome 网页到本地书库、再到 Agent 查询的流程。无需预装 Node、Python 或 WSL。

从 [测试版发布页](https://github.com/Richology/bookleap-downloads/releases/tag/v0.1.0-trial.2) 选择系统安装包，并可用同页 SHA256SUMS.txt 核对下载文件。

## Mac（Apple Silicon：M 系列芯片）

1. 下载 `.dmg`，打开后将「书跃本地同步助手」拖到「应用程序」。先安装到固定位置再配置 Agent，避免路径变化。
2. 从「应用程序」打开助手。此测试版没有 Developer ID 签名与 Apple 公证。如系统提示无法验证开发者，在确认下载来自本发布页后，可在「系统设置 → 隐私与安全性」对该应用选择「仍要打开」。不需要关闭整个系统的安全保护。被管理的设备可能禁止放行。
3. 若已有旧助手运行，先从旧助手选择「退出助手」，再启动新版本；已有知识库与配对保留。

Intel Mac 本轮不提供安装包。

## Windows（x64）

1. 下载 `.exe` 并运行，完成安装后从开始菜单打开「书跃本地同步助手」。默认按当前用户安装，无需 WSL。
2. 未签名测试版可能显示“未知发布者”或 SmartScreen 警告。仅在确认来源后，按系统提供的“更多信息 → 仍要运行”继续。企业策略或 Smart App Control 可能直接阻止；这种情况下本测试版暂不适用于该设备，不要求关闭系统防护。

## 配对与查询

1. 从网页「本地 MCP」下载安装并打开助手，点击网页「已打开助手，下一步」。助手已准备默认保存目录，也可在配对前更改；点击助手「连接网页」生成配对码。
2. 用 Chrome 打开 https://www.bookleap.cn/workspace，进入「本地 MCP」，粘贴配对码并授权。在助手弹出的来源确认中核对 `https://www.bookleap.cn`。
3. Chrome 提示本地网络权限时允许书跃连接助手。线上与 localhost 需分别配对。
4. 默认同步自己的拆书分析，体验书不参与，个人记录需单独授权。以页面显示的本地确认数量与时间为准。
5. 助手「连接 Agent」提供本地 MCP 参数。Codex 有配置预览快捷入口；其他支持本地 stdio MCP 的客户端按自己的格式填写 command、args、env。
6. 网页配对成功后直接显示「连接 Agent」步骤与可复制的验收问题。回到 Agent，重新连接 MCP 或重启客户端，再粘贴问题；返回自己的真实书名与对应内容才算完成。自动工具测试不等于已连接你的 Agent。

若显示已同步 0 本，先在网页上传一本自己的书或导入已有备份；内置体验书不参与同步。同步范围、个人记录授权与暂停按钮收在「同步设置」中，首次连接无需修改。

## 运行与更新

- 网页和助手同时运行时自动保存；关闭助手窗口会继续后台运行，退出助手才停止接收。
- 关闭网页后仍能查询已存内容；网页与助手恢复后补同步。
- 本测试版关闭自动更新。更新时退出旧助手，手动下载安装新版；不会主动删除已有书库。移动安装位置后，Agent 连接参数也需更新。
- Windows 可从系统“已安装的应用”卸载；Mac 退出后移除应用。默认保留知识库，清除副本需在助手中单独确认。

## 当前限制

仅 Chrome 是本轮网页试用目标，Safari 扩展尚未完成启用验收。安装包没有发行者代码签名，不能保证所有系统安全策略允许启动。真实用户数据、多客户端兼容、登录自启以及签名更新/回退仍需后续验收。使用云模型时，Agent 查询返回的片段可能进入模型上下文。
