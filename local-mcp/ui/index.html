后台运行与打开方式
  • 新内容保存时，网页和助手需要同时运行。无需每次打开网页「本地 MCP」面板。
  • 关闭助手窗口，只隐藏到后台；退出助手或暂停同步，会停止新内容落盘。
  • 关闭网页后，已保存内容仍可通过独立 MCP 查询；未送达内容在网页与助手恢复运行后补同步。
  • Mac 正式安装后，从「应用程序」或 Spotlight 搜索「书跃本地同步助手」打开；Windows 从开始菜单搜索同名应用。
  • 运行时可点击菜单栏或系统托盘图标。本机试用包仍从保存的 .app 位置打开。
清除本地数据

只清除助手管理的副本与配对，保留浏览器原记录。已进入 Agent 对话的内容无法撤回。
